# Write on the page itself

Edmundz opens your file **rendered**. Click a word and the syntax appears only where you are: *italic*, <ins>underline</ins>, ~~strikethrough~~, `code`, and [links](https://github.com/jaydenrasmussen/Edmundz).

- [x] GitHub Flavored Markdown
- [x] Mermaid diagrams and LaTeX, drawn in the text
- [ ] Your next sentence

> [!TIP]
> It is still plain Markdown on disk.
